# RTCtester

《开源平台与创新实践》实验工程：基于 Arduino 的 DS1307 实时时钟 + TM1637 四位数码管时钟。

工程源码由课程提供，用于练习 Git 本地版本管理与 GitHub SSH 免密推送流程。

## 硬件清单

| 元件 | 数量 | 说明 |
|---|---|---|
| Arduino UNO（或兼容板） | 1 | 主控 |
| DS1307 RTC 实时时钟模块 | 1 | 带纽扣电池，掉电走时 |
| TM1637 四位数码管模块 | 1 | 两位一组，用于显示 |
| 杜邦线 | 若干 | 连接模块与开发板 |

## 接线方式

### DS1307（I2C，走 UNO 硬件 I2C 引脚）

| DS1307 | Arduino UNO |
|---|---|
| VCC | 5V |
| GND | GND |
| SDA | A4 |
| SCL | A5 |

### TM1637（自定义引脚，见程序开头宏定义）

| TM1637 | Arduino UNO |
|---|---|
| VCC | 5V |
| GND | GND |
| CLK | D10 |
| DIO | D9 |

## 依赖库

编译前需安装以下两个库（课程压缩包内已提供 `.zip`，在 Arduino IDE 中通过「草图 → 导入库 → 添加 .ZIP 库」安装）：

- **RTClib**（Adafruit）—— 驱动 DS1307，提供 `RTC_DS1307` 与 `DateTime`
- **TM1637**（avishorp）—— 驱动四位数码管，提供 `init()` / `display()` / `point()` / `set()`

## 使用方法

1. 按上表完成接线，装入纽扣电池，USB 连接开发板。
2. 打开 `RTCtester.ino`，确认两个库已安装，点击「验证」编译。
3. 上传烧录后打开串口监视器，波特率 **9600**。
4. 上电时数码管先显示 `A b C d` 约 3 秒（自检），随后转为显示「分:秒」，中间小数点每秒翻转一次。

## 程序说明

| 函数 | 作用 |
|---|---|
| `setup()` | 初始化串口与数码管，检测 RTC 是否存在、是否在走时；若 RTC 停走则以编译时间校准 |
| `loop()` | 每秒读取一次 `RTC.now()`，取分、秒的十位与个位送数码管显示，并翻转中间小数点 |

亮度由 `tm1637.set(2)` 控制（0 最暗、7 最亮）。引脚定义在文件开头，可自行修改。

## 注意事项

- 工程路径请勿包含中文字符，否则部分工具链会报错。
- 首次上电若串口打印 `Couldn't find RTC`，检查 SDA/SCL 是否接反、模块是否供电。
- 若打印 `RTC is NOT running!`，说明纽扣电池没电或未装，程序会用编译时刻自动校准一次。
